# demostradoriaweb

Sitio web estático del demostradoriaweb proyecto financiado por los fondos europeos. Construido con [Astro](https://astro.build) y Tailwind CSS.

Páginas: Inicio, Retos (Lenguaje, Visión), Hardware, Servicios y Noticias.  
Las noticias se gestionan como archivos Markdown en `src/content/noticias/`.

## Comandos

Todos los comandos se ejecutan desde la raíz del proyecto, desde un terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
| `npm run preview`         | Preview your build locally, before deploying     |
| `npm run astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `npm run astro -- --help` | Get help using the Astro CLI                     |
